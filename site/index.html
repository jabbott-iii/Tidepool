Tidepool

A zero-dependency IDE written in Rust from the ground up: a native GUI in jabbott.dev's style, a terminal UI with vim-style editing, first-class Rust and Markdown, managed toolchains, Android and iOS builds, and AI through plugged-in agents. So far it shows only its empty shell, in a window this page cannot show, so below are its gate and two of its libraries, run on the build named beside them.
